# Smoke-тест перед релизом

Пройдите на **продакшене** (GitHub Pages + Fly API) после деплоя.

## Инфраструктура

- [ ] `curl https://ffhoreca-api-tips-from-trips.fly.dev/api/health` → `{"ok":true}`
- [ ] `VITE_API_BASE_URL` в GitHub Secrets указывает на Fly API
- [ ] `CORS_ORIGIN` на Fly включает URL GitHub Pages
- [ ] Google OAuth redirect URI — прод callback
- [ ] SMTP-секреты заданы (`fly secrets list`)

## Авторизация и карта

- [ ] Вход через Google
- [ ] Автооткрытие аккаунта без юзернейма → сохранение юзернейма
- [ ] Переход на `/{username}`
- [ ] Добавить город, место, маршрут
- [ ] Toast при приближении к лимиту Freemium
- [ ] 403 при превышении лимита

## Социальное

- [ ] Поиск пользователя в избранном
- [ ] Открыть чужую публичную карту
- [ ] Приватная карта → блюр для всех, кроме владельца (избранное доступ не открывает)
- [ ] Удаление аккаунта в модалке аккаунта → выход и редирект на главную
- [ ] Email **не** виден в публичном профиле (DevTools → Network → `/api/users/...`)

## Обратная связь и legal

- [ ] Форма обратной связи → письмо на почту
- [ ] `/privacy` и `/terms` открываются
- [ ] Ссылки в футере и в аккаунте работают

## Локализация и мобилка

- [ ] RU ↔ EN
- [ ] Safari / Chrome на телефоне: шапка, карта, модалки
